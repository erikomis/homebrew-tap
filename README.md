# erikomis/homebrew-tap

Formulas do Homebrew do [GambiarraScript](https://github.com/erikomis/gambiarrascript).

```bash
brew install erikomis/tap/gambiarrascript
gs --version
```

A formula e gerada a cada release: o job `release` do repo principal imprime
ela preenchida (versao + sha256) no resumo da run.
